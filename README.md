# 🍽️ Zomato Restaurant Data Analysis – Tableau Dashboard

This repository contains an **Tableau dashboard** built using Zomato restaurant data to analyse restaurant distribution, cuisines, delivery options, and table booking trends across cities in India.

The dashboard is designed to provide quick insights into **restaurant availability, customer engagement (votes), cuisine preferences, and delivery/table booking patterns**.

---

### 🍛 Cuisine Analysis
- Top cuisines by restaurant count
- Popular food categories include:
  - North Indian
  - Chinese
  - Fast Food
  - Mughlai
  - Café & Bakery

---

### 🪑 Table Booking Analysis
- Restaurants offering table booking: **12.84%**
- Restaurants without table booking: **87.16%**
- Cities with the highest table booking availability:
  - New Delhi
  - Gurgaon
  - Noida

---

### 🚚 Online Delivery Analysis
- Restaurants offering online delivery: **28.01%**
- Restaurants without online delivery: **71.99%**
- Top cities with online delivery:
  - New Delhi
  - Gurgaon
  - Noida
